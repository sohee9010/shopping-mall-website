## 재측정: 카테고리 성능 하락(66 → 58)은 측정 편차였다

위 표의 카테고리 측정은 다른 빌드가 함께 돌던 중이었다. 같은 조건(다른 작업 없음)에서 main과 D-3를 각각 5회 측정했다.

| 빌드 | JS 합계 | 성능 5회 | TBT | JS 실행 시간 |
|---|---|---|---|---|
| main | 1,015KB | 72 / 71 / 72 / 72 / 71 | 0~11ms | 170~195ms |
| D-3 | 1,063KB | 71 / 72 / 71 / 72 / 71 | 0~43ms | 208~385ms |

- 점수 차이 없음. 실제 비용은 JS +48KB(React Query)·실행 시간 약 +60ms
- 카테고리의 실제 병목은 LCP 7.8초(외부 상품 이미지) → D-4 상품 이미지 교체에서 다룸
